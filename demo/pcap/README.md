# Примеры трафика PCAP

Готовые синтетические записи Ethernet-трафика, по 10 000 пакетов в файле.
Созданы генератором из `demo/load_test.py`; это не захват реальной сети.
TCP-пакеты содержат тестовые данные без установления TCP-сессии.
Временные метки фиксированы для воспроизводимости.

| Файл | Содержимое | Read / IPv4 TCP/UDP |
| --- | --- | --- |
| tcp-small.pcap | TCP, 16 байт данных | 10000 / 10000 |
| udp-small.pcap | UDP, 16 байт данных | 10000 / 10000 |
| mixed.pcap | TCP, UDP, ARP по очереди | 10000 / 6667 |
| large-payload.pcap | TCP, 1400 байт данных | 10000 / 10000 |
| many-flows.pcap | TCP с разными IP и портами отправителя | 10000 / 10000 |
| non-ipv4.pcap | ARP | 10000 / 0 |

Запуск из корня Dozor:

```sh
./build/dozor --pcap demo/pcap/mixed.pcap
```

Все шесть файлов проверены существующим `build/dozor`: код возврата 0,
пустой stderr и ожидаемые итоговые счётчики.
`manifest.json` содержит размеры, число пакетов и SHA-256 каждого PCAP.
